# Unit Four 宠物店争夺战 · Pet Shop Battle

小学英语三年级 **Unit Four（Revision A / Revision B，P32–P36）** 配套的课堂互动复习游戏。
纯前端单文件，**双击 `index.html` 即可运行**，不联网、不装插件、不依赖任何外部资源。

---

## 一、怎么玩

打开后首页选择模式，然后开始：

| 模式 | 说明 |
|---|---|
| **双人对抗** | 同屏抢答。倒数 3-2-1-GO 后，玩家1 按 **A 键** / 拍屏幕**左半边**，玩家2 按 **L 键** / 拍**右半边**。先集满 **5 只动物**者获胜 |
| **单人练习** | 无对手、无倒计时。答对一题收一只动物，慢慢想没关系 |

**规则**
- GO 亮起前抢按 = 抢跑，罚停一下
- 答错**不扣分**，换对手补答，答对就归他
- 答错会记进「错题总结」，结算时给出正确答案

**操作方式**：全程只需**点击**和**拖拽**，不需要打字、不需要开口说英语。

## 二、覆盖的课本知识点

- **动物词汇**：dog / cat / panda / monkey / elephant / zebra / sheep / duck / rabbit / lion
- **数字**：one – fifteen（1–15）
- **can 句型**：`I can help people get around.` `I can find people.` `I can find sheep.` `I can be your good friend.`

**题型（8 种）**

| 题型 | 练什么 |
|---|---|
| 听音选动物 | 单词听力辨音 |
| 看图选单词 | 词义识别 |
| 听音选数字 | 数字听力 |
| 看数字选单词 | 数字认读 |
| 补全单词 | 字母拼写（点字母卡，非打字） |
| 数字配对 | 英文↔数字（拖拽） |
| 动物配对 | 英文↔图片（拖拽） |
| 狗狗能做什么 | can 句型理解 |

## 三、界面上的几个开关

| 控件 | 作用 |
|---|---|
| **朗读语速**（慢 / 标准 / 快） | 默认「标准」0.85。点一下会立刻试读一句，可当场试听 |
| **中文提示**（默认关） | 打开后答题区显示中文提示。**提示只说怎么做，不直接给答案** |
| **试听语音** | 检测设备朗读是否正常 |
| **我的动物图鉴** | 查看本轮收集到的动物。**图鉴只记录本轮，换设备或重开页面会重新开始** |

## 四、技术实现

- 单个 HTML 文件，内嵌 CSS、JavaScript 与 10 张卡通动物图（base64）
- 音效用 Web Audio API 实时合成；朗读用浏览器内置 `speechSynthesis`（英文 en-US）
- 支持电脑键盘（A / L）与平板、手机触屏（左右半屏多点触控）
- 无跨域、无后端、无 Cookie

**浏览器要求**：Chrome / Edge / Safari 均可。**朗读功能在 Chrome、Edge 上效果最好**；Safari 需先允许网页播放声音。

## 五、部署到 GitHub Pages

1. 新建仓库（如 `unit4-pet-shop`）
2. 把 `index.html` 上传到仓库根目录
3. 进入 **Settings → Pages**
4. **Source** 选 `Deploy from a branch`，**Branch** 选 `main`、目录选 `/ (root)`
5. 点 Save，等约 1 分钟，即可通过
   `https://<你的用户名>.github.io/<仓库名>/` 访问

之后把链接发给学生，手机、平板、电脑都能直接打开玩。

## 六、常见问题

**打开是空白 / 界面是旧版**
按 `Ctrl + F5`（Mac 为 `Cmd + Shift + R`）强制刷新。右下角显示的版本号可用于确认是否最新版。

**听不到朗读**
先点首页「试听语音」。若听不到：
- 检查设备是否静音、音量是否打开
- 换用 Chrome 或 Edge 浏览器
- 网页音量上限由浏览器设定，已设为最大，再大只能调设备音量

**按钮点了没反应**
确认是最新版。旧版本存在按钮类名冲突问题，已在最新版修复。

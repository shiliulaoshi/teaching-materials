怎么玩：顾客上门 → 双人对抗模式倒数 3-2-1-GO 后抢答 → 抢到的人作答 → 答对把动物收进自己的宠物店，先集满 5 只者获胜。
抢答方式：平板 / 手机 → 拍屏幕左半边（玩家1）或右半边（玩家2）；电脑 → 按 A 键 或 L 键。
GO 亮起前抢按 = 抢跑，要罚停一下。答错不扣分，换对手补答，答对就归他。
单人练习：没有对手、没有倒计时，答对一题收一只动物，慢慢想没关系。
题目范围：课本里的动物、数字 1–15 和 can 句型，全部点一点、拖一拖就能答；答题区全英文，同一局里出过的题不会重复出现。
